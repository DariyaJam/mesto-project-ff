# Проектная работа "Mesto"
Стек: HTML, CSS, JavaScript, Webpack
  
Проект опубликованный на gh-pages: https://dariyajam.github.io/mesto-project-ff/
## Установка и запуск
Для установки проекта необходимо выполнить
```terminal
npm install
```
Для запуска
```terminal
npm run start
```
## Описание проекта
Проект "Mesto" представляет собой сервис для публикации фотографий. Пользователь может создать пост с фотографией и её названием, поставить лайк, посмотреть количество лайков и удалить фотографию. Кроме того, пользователь может просматривать посты других людей, а также по желанию изменить имя, описание своего профиля и фотографию профиля (аватар).
## Реализация
Реализованный функционал и технологии:
1. Разработка и валидация пользовательских форм.
2. Динамическое обновление интерфейса: взаимодействие с DOM и обработка событий.
3. Взаимодействие с сервером через REST API.
4. Реализация асинхронной логики с использованием Promise и async/await.
5. Организация кода по принципам модульной архитектуры.
6. Настройка сборки проекта с помощью Webpack.
